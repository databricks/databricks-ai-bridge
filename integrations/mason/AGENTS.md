# Mason agent guide

Instructions for agents working in `integrations/mason`.

- **Developing or testing Mason** (editable install, how CLI / SDK-runtime / template changes are
  sourced, testing unreleased SDK changes, `mason dev` / `mason deploy` gotchas): follow
  [CONTRIBUTING.md](CONTRIBUTING.md).
- **Changing the CLI:** update the [`cli.md`](cli.md) command reference in the same change - see
  [Keeping docs in sync](CONTRIBUTING.md#keeping-docs-in-sync).
