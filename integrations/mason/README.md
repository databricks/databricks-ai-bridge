# Databricks Mason

`databricks-mason` is the Databricks integration package for Mason.

## Installation

From PyPI:

```sh
pip install databricks-mason
```

From source:

```sh
pip install 'git+https://github.com/databricks/databricks-ai-bridge.git#subdirectory=integrations/mason'
```

This initial package is intentionally minimal and provides the package namespace for future Mason integrations.
